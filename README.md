# FAQ-бот на 5 вопросов

Терминальное приложение загружает пять пар вопрос–ответ из `faq.txt`, ищет наиболее подходящий вопрос по совпадающим ключевым словам и выводит связанный ответ. Если совпадений нет, программа печатает `не знаю`.

Стек: Kotlin/JVM и Gradle. Для запуска требуется JDK 21–25 и доступ Gradle к Maven Central при первой сборке.

```bash
./gradlew build
./gradlew run
```

Пример работы:

```text
> Когда начинается обучение?
Обучение начинается в 10:00 по местному времени.
```

Тесты запускаются командой:

```bash
./gradlew test
```

Итог: минимальный CLI-бот без Ktor, RAG, LLM и внешних сервисов.
