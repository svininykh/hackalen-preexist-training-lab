# FAQ-бот на 5 вопросов

Бот читает пять пар вопрос–ответ из `faq.txt`, находит вопрос с максимальным пересечением ключевых слов и отвечает из файла. Если общих ключевых слов нет, выводится `Не знаю.` Модели и RAG не используются.

Запуск:

```bash
python3 faq_bot.py
```

Для выхода введите `выход`.
