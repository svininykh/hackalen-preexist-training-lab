# AI Usage

## Инструмент

OpenAI Codex.

## Роль AI

AI использовался как инструмент реализации задачи по требованиям, сформулированным человеком.

## Процесс

Human defines. AI implements. Tests verify. Human decides.

## Постановка задачи

Исходное задание было формализовано человеком как GitHub Issue #1.

## Что выполнял AI

Codex создал Kotlin/Gradle проект, реализовал загрузку FAQ и поиск по ключевым словам, добавил тесты, README и выполнил проверки сборки и CLI-сценариев.

## Проверка человеком

Человек определил требования, выбрал рабочую ветку, запускал команды в терминале и принимает решение о commit, merge и сдаче.

## AI в runtime

AI/LLM не используется в runtime. FAQ-бот работает детерминированно и не требует внешнего AI API.
